本轮里程碑 M1–M10 + T2

M1 · P0

Tombstone 语义

非底层保留删除标记；Get 三态 PointLookup。

M2 · P0

WAL 损坏尾

replay 后 ftruncate，避免静默丢后续记录。

M3 · P0

MANIFEST 恢复

截断损坏尾 + level_count 解耦。

M4 · P0

目录 fsync

rewriteSnapshot 后 fsyncDir。

M5

SST 错误传播

Corruption/IOError 上浮，禁止 silent NotFound。

M6

Bloom 生命周期

孤儿 .bloom 清理；按条数建 filter。

M7 · 最小

RAG 原子快照

tmp→fsync→rename；启动 RebuildFromStore。

M8 · 部分

网络边界

kMaxRequest + 写缓冲上限 + EPOLLOUT。

M9

MemTable O(log n)

SkipList lowerBound / seek；惰性 imm 迭代。

M10

删除一致性

store + side index + snapshot 对齐。

T2.1

流式 k-way merge

MergingIterator + 块惰性 SST 迭代 + 原子 rename。

T2.3

TableCache

路径 LRU 复用 reader；pread 消竞态。

T2.5

Write Stall

immutable/L0 阈值；可选 Status::Busy。

T2.6 · 最小

引擎 /metrics

原子计数器 + --metrics-port；scraper 探活。

修改前后对比 关键切片

Before

  • 非底层 merge 丢 tombstone
  • Get 把删除当 miss → 下层复活旧值

After

  • 仅最底层可丢 tombstone
  • PointLookup 三态；同层新文件优先
证据：compaction.cpp · internal_key.h · CompactionTombstoneTest

Before

  • readBlock 失败 → nullopt / NotFound
  • 损坏 SST 被更旧层「顶替回答」

After

  • lookup 返回 Status + PointLookup
  • DB::get 传播 Corruption/IOError
证据：sstable_reader.* · SSTableCorruptionTest（含删 WAL 后 reopen）

Before

  • lookup 全表 entries() 线性扫
  • 迭代器默认大向量拷贝

After

  • SkipList findGreaterOrEqual O(log n)
  • imm 惰性游标；live MemTable 仍快照（诚实边界）
证据：skip_list.h · memtable.cpp · MemTableSeekTest / SkipListSeekTest

Before

  • merge 可能整表装入内存
  • SST 迭代全文件快照

After

  • k-way MergingIterator 流式写出
  • 按块惰性 SSTableIterator；tmp→fsync→rename
证据：compaction.cpp · sstable_iterator.* · CompactionStreamTest

Before

  • C++ 引擎零指标
  • observability 只刮 Go 层

After（最小）
