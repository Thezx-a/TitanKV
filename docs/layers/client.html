总览/客户端层

Client Layer · 三种接入方式

客户端层提供三种接入：Next.js 控制台（人类）、Cobra CLI（运维/脚本）、Go SDK（机器对机器）。 三者最终都打 Gateway 的 :8080，鉴权方式各异。

Next.js 控制台 Cobra CLI · keyforge Go SDK titan JWT / APIKey SSE scan

核心组件知识点

keyforge CLI · Cobra 命令行

client-cli/main.go

用 spf13/cobra 实现的 KV 操作命令行工具，名叫 keyforge，通过 Gateway 调用。

  • 子命令：ping 健康检查、put <key> <value>、get <key>、scan --start --end（SSE 流式）。
  • 持久参数：--url（默认 http://127.0.0.1:8080，环境 TITANKV_URL）、--token（环境 TITANKV_TOKEN）。
  • 鉴权：addAuth() 注入 Authorization: Bearer <token>。
  • scan SSE：io.Copy(os.Stdout, resp.Body) 直接把流式响应打到标准输出。
  • 错误处理：resp.StatusCode >= 400 时返回 HTTP %d。
# ping
keyforge ping --url http://localhost:8080

# put (需 token)
keyforge put foo bar --token $TITANKV_TOKEN

# 流式 scan
keyforge scan --start a --end z --token $TITANKV_TOKEN

Go SDK · titan.Client

client-go/titan/client.go · types.go · errors.go

面向程序集成的 Go 客户端，支持 APIKey（机器对机器）或 JWT Login 两种鉴权，内置重试。

  • Client 结构：gatewayURL / apiKey / http / maxRetries。
  • Option 模式：WithMaxRetries(n)（默认 3）、WithHTTPClient(h)（自定义代理/超时）。
  • New(gatewayURL, apiKey, opts...)：apiKey 为空时用 JWT，单独调 Login。
  • 默认超时：10s。
  • API：Login / Put / Get / Delete / Scan 等。
  • 错误：errors.go 定义结构化错误类型。
  • 类型：types.go 定义 LoginResponse 等数据结构。

Web 控制台 · 人类接入

web/（详见 前端控制台层）
